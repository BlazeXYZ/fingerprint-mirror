How to defend yourself

There are two strategies: look like everyone else, or look different every time. Clearing cookies does neither.

Blend in

Use a browser that makes everyone identical

Tor Browser and Mullvad Browser report the same screen size, fonts, time zone and GPU for every user. You disappear into the crowd.

Randomize

Add noise to the readings

Brave adds small random changes to canvas, audio and WebGL output per site and per session, so the hash never matches twice.

Harden

Turn on Firefox fingerprinting protection

Enhanced Tracking Protection on Strict blocks known fingerprinting scripts. privacy.resistFingerprinting goes further, at some cost to convenience.

Block

Stop the scripts from running

Content blockers like uBlock Origin block many tracking scripts before they can collect anything. That only works for scripts already on their lists.

Simplify

Customize less

Every extra font, extension, language and unusual setting makes you rarer. The defaults are the crowd.

Myth

Private mode and VPNs don't help here

Incognito wipes cookies and a VPN hides your IP, but neither changes your fonts, GPU or screen. The fingerprint survives both.

How it works

When the page loads, about twenty collectors run in parallel. Each reads one family of signals using standard browser APIs: navigator, screen, Intl, Canvas 2D, WebGL, WebGPU, Web Audio, CSS media queries, the Permissions API and Speech Synthesis. Nothing asks for permission and nothing is sent anywhere. There is no server, so you can confirm it in your browser's network tab.

Signals that stay the same across restarts are combined into one 128-bit hash: your fingerprint ID. Signals that change all the time, such as window size, battery and network speed, are shown but left out of the hash. The page draws the canvas and runs the audio test twice. If the two results differ, your browser is adding noise, and those signals stop counting.

The uniqueness figure is an estimate. Real fingerprinting services compare you against a database of millions of other visitors. This page has no database, so each signal gets an entropy value based on published research (Eckersley, “How Unique Is Your Web Browser?”, 2010; Laperdrix et al., AmIUnique, 2016; Gómez-Boix et al., “Hiding in the Crowd”, 2018). That value is adjusted for how common your actual value is, then the total is scaled down because signals overlap. The 2018 study is a useful reality check: across two million real visitors, about a third of desktop browsers were unique. Mobile browsers were unique far less often.

Your last ten fingerprint IDs are kept in this browser's localStorage, only so you can see what changed between visits. Nothing else is stored.
